# Discard-gate sweep — prompt_v32, corrected truth labels

Generated by `gate_sweep_v32.py` from the `voter_v32_*` and `voter_v3_*` result files in this directory. No API calls. Truth: the corrected labels `human_truth_v31.json` (60 cases, 13 yes / 47 no), `heldout_truth_v31.json` (30, 10 yes / 20 no) and the 300 FLoRA entries in `flora_positive_cases.json` (all yes) — 323 positives, 67 hard negatives.

Every gate is written over the v3.2 binary `confident` field. v3 is swept alongside with `confidence == "high"` read as `confident`, so the same gate name means the same rule under both prompts.

These cases are derivation data (see `README.md`), so every number is in-sample. `schema_error` / `api_error` rows count as *not answered*, so a model that failed to answer can never contribute to a discard.

`F140` is an adjudication-pending FLoRA entry and is counted separately from the settled misses.

The 150-case proxy pool (`coding_v3_cases.json`, past production discards) was only run through flash-lite, so its column is a **single-model analogue** of each gate — for the soft gates, the confident-`none` half, since the qualifying-side clause needs a partner. It is comparable across prompts in level, but not to the hard-negative column.

- **G-strict** — both none, both confident
- **G-oneconf** — both none, >=1 confident
- **G-any** — both none, any confidence
- **G-softqual** — both none, or one none+confident and the other qualifying-or-unclear at confident=false
- **G-softqual-strict** — both none, or one none+confident and the other unclear at confident=false
- **G-strict [m]** — flash-lite+ministral: both none, both confident
- **G-oneconf [m]** — flash-lite+ministral: both none, >=1 confident
- **G-any [m]** — flash-lite+ministral: both none, any confidence
- **G-softqual [m]** — flash-lite+ministral: both none, or none+confident with an unconfident qualifying-or-unclear partner
- **G-softqual-strict [m]** — flash-lite+ministral: both none, or none+confident with an unconfident unclear partner
- **T-strict** — all 3 none, all confident
- **T-unan** — all 3 none, any confidence
- **T-maj** — >=2 of 3 none, >=1 of those confident
- **T-softqual** — all 3 none, or >=1 none+confident with every other voter unconfident qualifying-or-unclear
- **T-softqual-strict** — all 3 none, or >=1 none+confident with every other voter an unconfident unclear
- **T-maj-soft** — >=2 none (>=1 confident) and no voter asserts qualifying at confident=true
- **T-maj-soft-strict** — >=2 none (>=1 confident) and the third is none or an unconfident unclear
